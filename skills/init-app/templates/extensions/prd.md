# PRD extensions

Each level-two heading below is an extension point of the `prd` skill. Content
under a heading is applied at that point. Delete the headings you do not need;
an empty file is a no-op. Keep content declarative: questions, sections and
checklists. Procedure belongs in the skill, not here.
